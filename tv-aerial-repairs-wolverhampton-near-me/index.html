Checks before booking a local aerial repair

Start with the television's selected input. A set left on an unused HDMI input can show a blank screen even when the aerial connection is fine. For broadcast channels, check that you're using the television's tuner rather than a separate satellite receiver.

You can also inspect accessible indoor connections without opening equipment or moving heavy furniture. Switch equipment off before disconnecting leads, then check that each plug sits securely in its socket.

Keep a short checklist beside you:

  • Note the affected rooms and televisions.
  • Write down any message shown on screen.
  • Check whether all channels or only certain ones disappear.
  • Record when the trouble started and whether it comes and goes.
  • Mention recent decorating, furniture moves or changes to television equipment.

Don't buy replacement equipment just because a connection looks old. Its condition and performance need to be assessed together.
